# Sample DICOM Datasets

Questa cartella è destinata all'archiviazione di file di test in formato `.dcm` (Digital Imaging and Communications in Medicine).

### Struttura attesa
- `sample-study.dcm`: Radiografia toracica anonimizzata di test.
- Utilizzare questi file per testare l'importazione via API REST o tramite l'interfaccia web di Orthanc.
